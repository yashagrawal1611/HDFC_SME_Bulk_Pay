# HDFC SME Bulk Pay - GitHub Build Package

Upload all files in this folder to a new GitHub repository (public or private).

## Steps
1. Create a new GitHub repo.
2. Upload all files from this ZIP to the repo root.
3. Commit & push.
4. Go to the repo -> Actions -> Build HDFC SME Bulk Pay (Windows) -> Run workflow.
5. When finished, download the artifact `HDFC_SME_Bulk_Pay-windows.zip` and extract `HDFC_SME_Bulk_Pay.exe`.
